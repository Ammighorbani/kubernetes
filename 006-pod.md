## Pod is smallest component in kubernetes

### Pod is look like a bag you can put one or more containers in it but it's recommended put one or two containers not more, pod is a collection of container

---

### 1- You can create your own pod

**Input:**
```bash
kubectl run nginx --image=nginx
```
**Output:**
```bash
root@devops:~# kubectl get pods
NAME    READY   STATUS    RESTARTS   AGE
nginx   0/1     ContainerCreating   0          33s
```

`1` **:** **It's desire state**</br>
`0` : **It's current state and you must go to desire state**

**After few seconds:**
```bash
root@devops:~# kubectl get pod -o wide
NAME    READY   STATUS    RESTARTS   AGE   IP           NODE           NOMINATED NODE   READINESS GATES
nginx   1/1     Running   0          21m   10.244.2.2   fresh-ubuntu   <none>           <none>
```

### 2- You can see explanation about every things you want
```bash
kubectl explain pod

kubectl explain pod.metadata

kubectl explain pod.metadata.labels
```

---

### 3- You can see a namespace pods
```bash
kubectl get pod -n [POD-NAME]

kubectl get pod -n dev
```

---

### 4- You can create a pod in specefic namespace

```bash
kubectl run nginx --image=nginx -n dev
```

#### Note: If your cluster restart base on any reason your pod won't comes up again and you must have restart policy for your pods and write manifests

---

### 5- You can remove a pod
```bash
kubectl delete pod [POD-NAME]

kubectl delete pod -n [NS-NAME] [POD-NAME]

kubectl delete pod nginx

kubectl delete pod -n dev nginx
```

---

### 6- You can get logs of your pod
```bash
kubectl logs [POD-NAME]

kubectl logs nginx
```

#### Note: Your pod must be running to get logs

---

### 7- You can see status of a pod

```bash
kubectl describe pod [POD-NAME]

kubectl describe pod nginx
```

---

### 8- You can describe your nodes either

```bash
kubectl describe nodes [NODE-NAME]

kubectl describe nodes k8s-1
```

---

### 9- You can remove a namespace
```bash
kubectl delete ns [NS-NAME]

kubectl delete ns dev
```

#### Note: If you delete a namespace whole things in that namespace will remove either

---

### 10- You can use manifest files to create pods
```yml
apiVersion: v1
kind: Pod
metadata:
  namespace: my-ns
  name: nginx-pod
  labels:
    app.kubernetes.io/env: dev
    app.kubernetes.io/product: mci
spec:
  containers:
    - name: nginx-pod
      image: nginx
```

#### Note: One of the pod problems is you can't edit it and if you want to change somethigs in it you must one time delete your pod and change your manifest and then apply it again and actually you will have down time actually

#### Note: You can reconfigure your pod with apply it again

---

### 11- You can apply your manifest
```bash
kubectl apply -f pod.yml

kubectl apply -f [NAME.yml]
```

### 12- You can delete your things you have created with manifest file
```bash
kubectl delete -f pod.yml

kubectl delete -f [NAME.yml]
```

---

### 13- You can go into your pod
```bash
kubectl exec -it -n my-ns nginx-pod -- bash

kubectl exec -it -n [NS-NAME] [POD-NAME] -- bash
```

---

### 14- You can execute command into your pod
```bash
kubectl exec -it -n my-ns nginx-pod -- nginx -v

kubectl exec -it -n [NS-NAME] [POD-NAME] -- [COMMAND]
```

---

### 15- You can create multi containers pod
```yml
apiVersion: v1
kind: Pod
metadata:
  namespace: my-ns
  name: ubuntu-images
  labels:
    app.kubernetes.io/env: dev
    app.kubernetes.io/product: mci
spec:
  containers:
    - name: ubuntu-ammighorbani
      image: ubuntu
      command: ["/bin/bash", "-c", "while true; do echo hellow-ammighorbani; sleep 3; done"]
    - name: ubuntu-mamadhacker
      image: ubuntu
      command: ["/bin/bash", "-c", "while true; do echo hellow-mamadhacker; sleep 3; done"]
```

---

### 16- You can get your pods yamel manifest file
```bash
kubectl get pod -n my-ns ubuntu-images -o yaml
```
