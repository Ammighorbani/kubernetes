## Job is look like at in linux, we use job when we need to do a one time run things look like get backup of our database

### 1- You can write a job
```yml
apiVersion: batch/v1
kind: Job
metadata:
  name: myjob
  namespace: my-ns
spec:
  template:
    spec:
      containers:
        - name: myjob
          image: alpine
          command:
            - echo
            - "Hello world"
      restartPolicy: Never
```

#### Note: It's recommended to use never for restart policy, it's mean if in your job something be failed or crashed never run it again

#### Note: You can't have duplicate name job

---

### 2- You can remove a job
```bash
kubectl delete -n my-ns job myjob2
```
