## Horizontalpodautoscalers or hpa will autoscale your pods base on what you want, for example cpu percentage or memory

### 1- You can autoscale your deployment
```bash
kubectl autoscale -n my-ns deployment myapp --cpu=20 --min=4 --max=10

kubectl autoscale -n [NS-NAME] deployment [DP-NAME] --cpu=[PERCENT-NUMBER] --min=[NUMBER] --max=[NUMBER]
```

---

### 2- You can see your hpa
```bash
kubectl get hpa -n my-ns
kubectl get hpa -n [NS-NAME]
```

---

### 3- You can edit your hpa
```bash
kubectl edit -n my-ns hpa myapp
kubectl edit -n [NS-NAME] hpa [DP-NAME]
```

---

### 4- You can remove your hpa
```bash
kubectl delete -n my-ns hpa myapp
kubectl delete -n [NS-NAME] hpa [DP-NAME]
```
